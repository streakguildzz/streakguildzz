## Welcome to my corner of GitHub — I'm streakguildzz 👋

I spend most of my time writing Rust and C, usually somewhere between the kernel and the terminal. I like understanding how things actually work underneath — why a syscall behaves the way it does, where the cycles go, what the compiler decided to do with my code. Lately I've been drawn to WebAssembly as a compilation target, partly because it forces me to think carefully about what a runtime really needs to provide.
